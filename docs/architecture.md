# Архитектурная схема

Для проекта выбрана модульная архитектура.

                      ┌──────────────────┐
                      │      Клиент      │
                      └────────┬─────────┘
                               │
                               │ HTTP
                               ▼
                      ┌──────────────────┐
                      │     ApiHost      │
                      │ ASP.NET Core API │
                      └────────┬─────────┘
                               │
              ┌────────────────┼─────────────────┐
              │                │                 │
              ▼                ▼                 ▼
     ┌────────────────┐ ┌───────────────┐ ┌────────────────┐
     │ MovementModule │ │CatalogModule  │ │InventoryModule │
     └───────┬────────┘ └───────────────┘ └───────▲────────┘
             │                                     │
             │ проверка товара                     │
             └─────────────────────────────────────┘
             │
             │ изменение остатков
             ▼
     ┌────────────────┐
     │InventoryModule │
     └────────────────┘

Центральным модулем бизнес-процесса является `MovementModule`.

При регистрации отгрузки он:
1. получает данные контрагента;
2. проверяет наличие товара в каталоге;
3. проверяет достаточность остатка;
4. создаёт документ движения;
5. уменьшает остаток в модуле учёта.
