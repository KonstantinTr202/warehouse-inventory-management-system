# Проверка складских операций

Тестовый проект `tests/WarehouseInventory.UnitTests` включён в `WarehouseInventory.slnx`. На исходном состоянии этапа 5 исполнялся один тест-заглушка с `Assert.True(true)`; файл с интеграционной заглушкой в решение не включён. Поэтому успешный запуск исходного набора не подтверждал поведение системы.

На этапе 5 добавлены настоящие тесты `StockUpdateServiceTests` для увеличения остатка 10 + 20 = 30 и ошибки `INSUFFICIENT_STOCK` без изменения остатка, как требовалось в отчёте этапа 4. Дополнительно проверены комбинация прихода и отгрузки, нулевое и отрицательное количество, null-запрос, отменённый токен и конкурентные списания в одном экземпляре сервиса.

```bash
dotnet restore WarehouseInventory.slnx
dotnet build WarehouseInventory.slnx
dotnet test WarehouseInventory.slnx
dotnet format WarehouseInventory.slnx --verify-no-changes
```

Эти тесты проверяют сервис с памятью процесса, не базу данных. HTTP-маршруты дополнительно проверены отдельным локальным запуском и запросами; автоматизированного интеграционного HTTP-тестового проекта пока нет.
